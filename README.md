# BusinessMate releases

Downloads en updates voor **BusinessMate** van [Mktngmate](https://mktngmate.com).

Deze repository bevat geen broncode, alleen:

- **Releases**: de BusinessMate-app en de command-line launcher voor macOS, Windows en Linux, met `SHA256SUMS`.
- **`channels/`**: het ondertekende updatekanaal (`stable.json` + `stable.json.sig`). De app controleert de
  handtekening voordat hij een update installeert.
- De AI-omgeving staat als image op `ghcr.io/thomasso180/businessmate-runtime` en wordt op digest (`sha256:…`) opgehaald.

Installeren en hulp: <https://mktngmate.com/download>
